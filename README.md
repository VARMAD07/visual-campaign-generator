# Visual Campaign Generator

This project was developed as a part of the coursework of Google AI for building apps.

An AI-powered creative workflow application for generating promotional campaign assets, visual concepts, and branded content using Google AI Studio and Gemini models.

Visual Campaign Generator explores how AI-assisted design workflows can accelerate creative ideation, reduce repetitive design work, and help users move from concept to campaign faster.

This project experiments with modern “vibe coding” workflows, where natural language prompting, rapid iteration, and AI-assisted development are used to build functional software quickly and creatively.

---

# Why I Built This

Creating promotional content often takes more time than expected.

Students, creators, clubs, startups, and small teams frequently struggle with:
- turning ideas into polished visuals,
- maintaining design consistency,
- creating multiple campaign formats,
- and organizing creative assets efficiently.

I wanted to explore whether AI could help simplify and accelerate the early stages of visual campaign creation while keeping the workflow accessible and organized.

The goal was not to replace designers, but to experiment with AI as a creative acceleration tool.

---

# Understanding Vibe Coding

This project was developed using a workflow commonly referred to as “vibe coding.”

Instead of manually building every system from scratch, vibe coding focuses on:
- communicating ideas clearly to AI systems,
- iterating rapidly,
- refining outputs,
- debugging generated code,
- and transforming concepts into working applications through natural language instructions.

The process becomes less about writing every line manually and more about:
- product direction,
- creative problem-solving,
- workflow design,
- and iterative refinement.

This project is part of my broader exploration into how AI is changing modern software creation and creative workflows.

# Features

## AI-Assisted Campaign Generation

Users can generate campaign concepts and promotional assets for:
- student events,
- creator campaigns,
- startup launches,
- product announcements,
- social media promotions,
- and community projects.

---

## Template Support

Templates are designed for:
- social media posts,
- email headers,
- simple ad banners,
- announcement graphics,
- and lightweight promotional assets.

---

## Brand Asset Uploads

Users can upload and organize:
- logos,
- images,
- visual references,
- and other brand assets.

This helps maintain visual consistency across campaigns.

---

## Project-Based Organization

Campaigns and assets are organized by project to create a cleaner and more manageable creative workflow.

---

## Export Support

Generated assets and campaign outputs can be exported in:
- PNG,
- JPG,
- and SVG formats.

---

The application focuses on:
- clean layouts,
- elegant typography,
- responsive design,
- subtle motion,
- and minimal visual clutter.

The goal was to create an experience that feels closer to a lightweight creative studio rather than a generic AI generator.

# Prompt Engineering Process

A major part of this project involved learning how prompt structure directly affects generated software quality and workflow behavior.

Below is an example of one of the development prompts used during the creation process.

## Initial Build Prompt

```text
Build a modern AI-powered web app called “Visual Campaign Generator.”

The app should help users create promotional campaign assets quickly using AI-assisted workflows.

Users should be able to:
- select a campaign type,
- describe their event, product, or announcement,
- choose a visual style,
- generate promotional visual concepts and campaign assets.

Templates should support:
- social media posts,
- email headers,
- simple ad banners,
- announcement graphics.

Users should also be able to:
- upload brand assets,
- organize assets by project,
- manage campaign workflows,
- export designs in PNG, JPG, and SVG formats.

The interface should feel modern, creative, clean, responsive, and visually polished.
```

This project is intended for creative experimentation and workflow acceleration.

Important notes:

- Users should avoid uploading sensitive or confidential information.
- Final campaign quality and branding decisions should still involve human review and creative judgment.
